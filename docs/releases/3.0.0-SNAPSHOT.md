# Datafaker 3.0.0-SNAPSHOT (dd-mm-yyyy)

## What's changed

See the [3.0 upgrade guide](../documentation/upgrade-3.0.md) for API replacements and migration examples.

* [#1932](https://github.com/datafaker-net/datafaker/pull/1932) `Stock.nyseSymbol()` now returns only common stock currently listed on NYSE: preferred shares, warrants, ETFs and delisted tickers were removed, shrinking the list from ~2650 to 1429 distinct symbols. Seeded outputs of `nyseSymbol()` change, and `unique()` runs out of values sooner.
* [#1940](https://github.com/datafaker-net/datafaker/pull/1940) SQL generation now escapes schema, table and field names inside quotes. Most dialects double the closing quote. BigQuery and ClickHouse quote names containing backslashes and use backslash escapes for backticks and backslashes. Oracle rejects double quotes in identifiers with `IllegalArgumentException`. Pass raw schema and table names if your code previously escaped them.
* Use `selection().oneOf()` and `selection().setOf()` in place of the deprecated Options provider. [#1885](https://github.com/datafaker-net/datafaker/pull/1885)
* `timeAndDate()` accepts `TemporalUnit` values for relative timestamps. [#1912](https://github.com/datafaker-net/datafaker/pull/1912)
* Bulk Java record transformations preserve input order and produce one output record per input. [#1953](https://github.com/datafaker-net/datafaker/pull/1953)
* Text and password methods can require a lowercase letter. [#1969](https://github.com/datafaker-net/datafaker/pull/1969)
* Vietnamese full names put the family name first. [#1984](https://github.com/datafaker-net/datafaker/pull/1984)
* Native Image builds use generated reachability metadata for Datafaker providers and locale resources. [#1913](https://github.com/datafaker-net/datafaker/pull/1913)
* `doWith` isolates temporary locale and seed settings on the calling thread. [#2000](https://github.com/datafaker-net/datafaker/pull/2000)
* Default random generation, locale fallback, and bulk exports are faster in the benchmarked workloads. [#2001](https://github.com/datafaker-net/datafaker/pull/2001)
