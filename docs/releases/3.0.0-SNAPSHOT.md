# Datafaker 3.0.0-SNAPSHOT (dd-mm-yyyy)

## What's changed
* [#1932](https://github.com/datafaker-net/datafaker/pull/1932) `Stock.nyseSymbol()` now returns only common stock currently listed on NYSE: preferred shares, warrants, ETFs and delisted tickers were removed, shrinking the list from ~2650 to 1429 distinct symbols. Seeded outputs of `nyseSymbol()` change, and `unique()` runs out of values sooner.
* [#1940](https://github.com/datafaker-net/datafaker/pull/1940) SQL identifiers (schema, table and field names) are now escaped per dialect: closing quotes are doubled (e.g. `[t]]2]`, `"t""2"`, `` `t``2` ``). BigQuery escapes backtick/backslash with backslash (`` `t\`2` ``); Oracle rejects double quotes in identifiers with `IllegalArgumentException`. Potentially breaking for identifiers that previously contained unescaped closing quotes.
